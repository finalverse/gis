# FinalGIS product identity

The separately packaged FinalGIS.app has org.finalverse.finalgis identity,0.1.0 package metadata, original Finalverse icon assets, a private QGIS profile, branded window title, World Engineering dock, menu entry and About FinalGIS dialog. The running host remains QGIS and retains its menu/attribution, professional functionality, public APIs and file formats. This is a supported product extension/launcher, not a fully renamed QGIS fork or accepted signed distribution.

The user-provided Finalverse_logo_07.svg and Finalverse_logo_03.icns were copied unchanged from the authorized brand directory. The label, startup workspace and README use FinalGIS consistently; upstream namespaces and internal library names are preserved. The runtime install is private under the evidence directory, not /Applications. Its original official app bytes/signature are preserved. package_app.py reproduces a fresh application/profile without touching an existing profile or upstream resources.
