# Source and runtime audit

Preserved repository: finalverse/FinalGIS, original origin/master e35c88781a9baff59081dafd2a92dad969d87a6b. This is complete QGIS development source (CMake version4.3). Original history, AGENTS.md, COPYRIGHT/COPYING and symbols stay intact. Product changes live under finalgis/. Plugin-first integration was selected over subtree duplication, symbol renaming or a large downstream patchset.

Selected stable desktop foundation: QGIS 3.44.15 Solothurn LTR, tag final-3_44_15, commit44b4ef051784192d6e4829dc008bca120e4d2388, official universal macOS DMG SHA256302547ebee16d4d38ddfd509469cc86e337b23c545307cdbe13c2c2d233ab7cb. Its source CMake/INSTALL were inspected: Qt5.15.2 minimum (Qt6 experimental), Qt6 path C++17, PROJ≥8.1; documented GDAL≥3.2 and GEOS≥3.9. Mature subsystems inspected include src/core,gui,3d,providers,analysis,app,python and Processing plugins. Actual runtime Qt5.15.19/Python3.12. This distribution is used as a prebuilt foundation, not claimed as a source build.

QGIS 4.2.3 stable (commitb041a18904a4dc9fdada8ecb2c84385054ddfee1) was checksum-verified and passed native provider/Processing tests headlessly. Its macOS GUI fails before plugin load at QgsMacNative::setIconPath/QImage::toCGImage, matching [upstream issue67981](https://github.com/qgis/QGIS/issues/67981). The LTR runs without modifying upstream binaries. See foundation.lock.json for exact installers/pins. Official [download](https://qgis.org/download/) and pinned [installation source](https://github.com/qgis/QGIS/blob/44b4ef051784192d6e4829dc008bca120e4d2388/INSTALL.md).

Never rewrite the preserved origin/master history. macOS arm64 is the only executed platform; marketplace-wide plugin compatibility and full QGIS source compilation are not certified.
