# Ecosystem integration boundary

FinalGIS supplies geographic editing, validated source context, reviewed native processing plans and local world exports. Its existing World Engineering entry remains operational. Models select bounded recipes; they do not gain publication or world mutation authority.

| Component | Boundary | Current desktop status |
| --- | --- | --- |
| Native GIS worker | C17/C++ geographic operations; separate Qt 6 process | Built and exercised against public fixtures |
| QGIS foundation | Desktop editing, providers, CRS, Processing and 3D | Preserved/tested 3.44.15 runtime |
| Core Native SDK / FWD | Typed interoperability and canonical world definition | Existing CLI/library contracts preserved; no new automatic desktop connection |
| SpatialDB | Validated publication/readback and provenance | Existing repository scripts remain; no configured live desktop publisher in this package |
| Cloud / Genesis / Forge | Governed generation, validation and publication | External future/configured integration; no fabricated buttons or receipts |
| Finalverse Map Server | Geographic representation, terrain/LOD and map services | Future milestone; not implemented by rebranding |
| MutSea / WorldLine | Authorized live state and causal history | External authority; local exports do not commit effects |
| Storm / Viewer / Studio | Scene rendering, experience and asset refinement | Existing ecosystem boundaries; no GIS engine replacement or new transport in this task |

The primary product Help/About explicitly distinguish working local workflows from unconfigured services. Third-party asset marketplaces, OpenUSD, SimReady and native MutSea/FMS roadmaps are strategic context, not capabilities delivered by changing app identity.

Next: FinalGIS AI-Native Geographic World Creation, with validated context retrieval, inspectable plans, authentic publication and authority integration. It should extend the mature foundation and preserve source/derived-content provenance, rather than start a wholesale GIS rewrite.
